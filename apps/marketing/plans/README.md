## Recommended execution order

1. **005** first — it adds the shared `--ease-out-strong` easing token to
   `globals.css:root`. 006 reuses that token.
2. **006** — reuses the token from 005 (falls back to adding it itself if 005
   was skipped).
3. **004** — isolated 2-line fix, no dependencies.
4. **003** — adds a reduced-motion `@media` block to `globals.css` plus Framer
   `useReducedMotion()` gates in `hero.tsx` and `process-flow.tsx`.
5. **001** — DotGrid loop rework (`colleges` route). Independent.
6. **002** — InteractiveGridPattern rework (`programs` route). Independent.

001, 002, 003, 004 are mutually independent and can be done in any order or in
parallel. 005 and 006 both touch `globals.css:root` (the token) — run 005 before
006, or let whichever runs first add the token.

## Dependencies & shared touch-points

- **`src/app/globals.css`** is touched by 003 (append `@media` block), 005 (add
  `--ease-out-strong` to `:root`), and 006 (reuse token). These edits are in
  different regions of the file and don't conflict, but if running in parallel,
  serialize the globals.css edits.
- **Reduced-motion ownership**: plan 003 owns hero + process-flow + the CSS
  marquees. Plans 001 and 002 each own their own component's reduced-motion gate
  (DotGrid and InteractiveGridPattern respectively). No overlap.
